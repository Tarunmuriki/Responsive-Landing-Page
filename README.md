# Responsive Landing Page

## 📌 Project Overview
This project is a simple and responsive landing page created using HTML5 and CSS3.  
The webpage includes:

- Responsive Header with Navigation Menu
- Hero Section with Call-to-Action Button
- Features Section
- Footer with Social Links
- Mobile Responsive Design using Media Queries

The project is designed to work properly on desktop, tablet, and mobile devices.

---

# 🎯 Objective
The main objective of this project is to understand and implement:

- HTML5 Structure
- CSS Styling
- Flexbox
- CSS Grid
- Responsive Web Design
- Media Queries

# 🛠 Technologies Used
